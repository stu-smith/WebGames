How to Play

Arrows

Arrows is a board-clearing logic puzzle. The grid is packed with arrows, each pointing in a direction. Click an arrow to fire it off the board along the way it points.

An arrow only escapes if its path to the edge is completely clear. If another arrow is blocking the way, the shot crashes and you lose. Choose your order carefully to clear every arrow off the board.

Controls

  • ClickFire the arrow off the board
  • SizeChange the board dimensions
  • HintsHighlight safe / unsafe arrows on hover
  • UndoTake back your last move
  • NewGenerate a fresh board

Tips

  • Arrows on the outer edges are usually safe to fire first.
  • Firing one arrow can open a path for others — plan chains ahead.
  • Turn on Hints while you learn to spot which shots are blocked.
