How to Play

Bubble Chain Blast

Bubble Chain Blast is a chain-reaction puzzle. Every level is packed with bubbles, each holding a number of dots. Tap a bubble to add a dot. When a bubble fills up it bursts, firing sparks in all four directions.

Each spark flies until it strikes the next bubble in its path, adding a dot there — which can make that bubble burst too. One good tap can set off a cascade that clears the whole board. Wipe out every bubble before you run out of taps.

Controls

  • ClickAdd a dot to a bubble
  • DifficultyBigger, busier boards
  • RetryReset the current level
  • NewGenerate a fresh level

Tips

  • Bubbles already holding three dots burst on the very next tap.
  • Aim for a bubble that will chain into a cluster, not a lone one.
  • Every level is solvable in exactly the taps you're given — plan ahead.
